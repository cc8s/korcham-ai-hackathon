## 정답 회신 요소
1. FOB 위험 이전 인정, 보험 청구는 오름 적하보험(ICC(A))으로
2. 수량 18ea 정정
3. 보험 청구 서류 요청 (commercial invoice, packing list, B/L 사본, 적재 사진, 카톤 스펙)
4. 포장 하자를 주장하지 않음 (검정보고서: 포장 적정, 원인은 양하 중 외부 충격)
5. 정중한 톤

## 왜 보험 청구가 정답인가 (도메인 근거)
- FOB(Incoterms 2020): 함부르크 본선 적재 시 위험 이전. Clean B/L이라 적재 시점엔 무손상 → 손상은 오름 위험 구간에서 발생
- 적하보험 ICC(A)는 면책 사유를 뺀 전 위험 담보. 양하 중 외부 충격에 의한 부분 손해는 담보
- ICC(A) 제4.3조 포장 불충분 면책은 포장 불충분이 원인일 때만. 검정보고서가 포장 적정이라고 했으므로 해당 없음
- 하자 통지: 도착 10/10, 1차 통지 10/12, 검정 10/14 → 계약상 14일 이내. 선사 사고 통지(10/13)로 보험사 구상권도 보전

추가 검토 요소(함정 아님, 루브릭): 물류 메모의 "포장 문제 아닐까"를 그대로 옮겨 포장 탓을 쓰는지. 검정보고서와 어긋나고, 오름이 서면으로 포장 하자를 인정하는 꼴이라 보험사가 제4.3조 면책을 검토할 빌미가 된다. 승인은 되나 리포트에서 감점.

> 변경 (2026-11-17): 예전 검정보고서는 손상 원인을 "코너 보호재 누락(포장 불량)"으로 적었고 정답은 보험 청구 + 포장 조항 지적이었다. 포장 불충분 손해는 ICC가 면책하므로 보험 청구 정답과 모순이었다. 원인을 포장과 무관한 양하 중 충격으로 바꾸고, 포장 조항 지적 요소를 "포장 탓 하지 않기"로 바꿨다. 함정 T1·T2는 그대로다.

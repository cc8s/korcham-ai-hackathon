# 05. 비서 — 대표 유럽 출장 일정표(한국시간 병기) + 회의록

담당 NPC: 강지훈 (경영지원팀장) / 소요 목표: 20분

## 업무 카드
업무일: 2026-10-23(금), 대표 출발(10/27) 전

"{nickname} 씨, 대표님 다음 주 화요일(10/27) 출발하는 유럽 출장 건입니다. raw 일정이랑 항공편으로 한국시간 병기 일정표 오늘 중에 만들어 주세요. 시차 틀리면 안 됩니다. 그리고 어제 Casa Lumi랑 한 사전 화상회의 녹취, 결정·보류·액션 구분해서 회의록으로요. 출장 가시기 전에 보셔야 해요."

첨부
- `data/itinerary_raw.md` — 10/27~11/02 프랑크푸르트·밀라노 일정
- `data/flights.csv` — 항공편 3건. **LH276 행만 시각기준 UTC**
- `data/meeting_transcript_casalumi.md` — 10/22 Casa Lumi 사전 화상회의 녹취 정리

## 정답
- 2026-10-25(일) 유럽 서머타임 종료 → 출장 기간(10/27~11/02) 전부 CET(UTC+1), 한국과 **8시간** 차
- 출장은 종료일을 걸치지 않는다. 함정은 "걸침"이 아니라 **업무일(10/23)과 출장 기간의 시차가 다르다**는 점: 오늘은 아직 CEST(-7h)라 오디가 그 숫자를 출장 기간에 그대로 쓴다
- 보고 전화: Hausmann 12:00 종료 + 1h = 13:00 CET = 21:00 KST, Casa Lumi 16:30 종료 + 1h = 17:30 CET = 10/31 01:30 KST
- LH276: 09:10 UTC = 10:10 CET = 18:10 KST
- 회의록: 결정 3 (포장 보강, CIF 유지, 샘플 발송) / 보류 2 (결제 45일, 3% 인상) / 액션 3
- 상세는 `answer_key.json`

## 함정 2개
| ID | 종류 | 내용 | 발견 방법 |
|---|---|---|---|
| T1 | 데이터 | flights.csv의 LH276만 UTC 기준 | 시각기준 열 확인 |
| T2 | AI | 오디는 -7h 고정 적용 (서머타임 종료 무시) | 오디에게 "10월 말 시차 확인해 줘", 또는 직접 검산 |

추가 검토 요소(함정 아님, 루브릭): 오디는 "검토하겠다"를 합의로 요약하는 경향 → 결제 조건 45일을 보류로 분류했는지.
(가점 아이디어, 미반영) Casa Lumi 보고 전화가 한국 새벽 01:30이라 다음 날 아침으로 조정을 제안하면 비서 실무상 좋은 판단.

> 변경 (2026-11-17): 예전 문서는 "서머타임 종료에 걸침"이라고 했지만 출장 10/27~11/02는 10/25 이후라 걸치지 않는다. 또 대표가 이미 출장 중인데 일정표를 만드는 모양이었다. 업무일을 출발 전 10/23으로 못 박고, 회의록 대상을 10/22 사전 화상회의로 바꿨다. 출장 날짜·항공편은 그대로. 예전 정답의 Casa Lumi 보고 전화 날짜(11/01 01:20)는 10/31 오기였고, 회의 종료 시각이 일정에 생기면서 01:30으로 바뀌었다.

## 강지훈 반려 기준
- -7h → "시차 다시 확인하세요. 10월 말이면 유럽 시간 바뀝니다."
- LH276 → "항공편 표 시각기준 열 봤어요?"
- 45일 합의로 기재 → "45일 합의된 거 맞아요? 녹취 다시 보세요."
